### REQ-AUTH-007 (+ REQ-RPT-001, REQ-USER-001, REQ-USER-005) — akses menu per role

Satu sumber kebenaran: matriks akses di `packages/shared` yang dipakai API dan web, supaya sidebar dan 403 tidak bisa berbeda.

| --- | --- | --- |
| Shared | `packages/shared/src/ej.ts` (baru: `MENU_ACCESS`) | `{ "daily-report": ["admin"], "home": [semua], "merge-ej": [semua], "user-management": ["admin"], "ej-parsing": [semua], "upload-ej": ["admin"] }` dan `canAccess(role, menu)` |
| API | [apps/ej-api/src/auth/requireAuth.ts](../../../apps/ej-api/src/auth/requireAuth.ts) | Ganti `adminOnly` dengan `requireMenu(menu)` yang membaca `MENU_ACCESS` |
| API | [apps/ej-api/src/app.ts:113-117](../../../apps/ej-api/src/app.ts) | `GET /api/users` dan `GET /api/users/:id` diberi `requireMenu("user-management")` |
| API | [apps/ej-api/src/ejRoutes.ts:91](../../../apps/ej-api/src/ejRoutes.ts) | `GET /reports/daily` diberi `requireMenu("daily-report")` |
| Web | [apps/ej-web/src/menu.ts](../../../apps/ej-web/src/menu.ts) | `MENU` difilter per role; `parseHash` mengarahkan route yang tidak diizinkan ke halaman awal role |

Test dulu:
- shared: `[REQ-AUTH-007] matches FSD Tabel 6.1 for every role and menu`
- ej-api: `[REQ-RPT-001] answers 403 to monitoring and vendor on the daily report`
- ej-api: `[REQ-USER-005] answers 403 to monitoring and vendor on every /api/users endpoint` (test lama "lets monitoring users view users" diganti)
- ej-web: `[REQ-AUTH-007] shows only Home and Merge EJ to vendor users`
- e2e: TC-E2E-008 login sebagai vendor, buka `#/daily-report` langsung → kembali ke Home
